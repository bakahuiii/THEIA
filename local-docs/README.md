# THEIA 本机资料目录

把希望北化顾问参考的资料手动放在这个目录中即可。支持常见的 PDF、Markdown、HTML、TXT、JSON、CSV、XML，以及 DOCX、PPTX、XLSX 文本提取。

这个目录只在本机读取：

- THEIA 和 `theia-buct-advisor` 只读，不会修改、上传或提交其中的文件。
- 资料不会自动加入模型上下文；只有 Agent 明确调用本地文档工具时才读取，并且每次读取有文件大小和字符数上限。
- 文档内容标记为 `untrusted`，不能替代 THEIA 的校园数据，也不能作为工具指令、登录凭据或学校事实。
- 本目录不进入安装包或源代码压缩包，也不应提交到 Git。请自行备份原始资料。

如需使用其他目录，可设置 `THEIA_LOCAL_DOCS` 环境变量。目录不存在时工具会返回“暂无本机资料”，不会猜测内容。
