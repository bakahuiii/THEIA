# 已废弃：P4-P5 预投影顾问运行时

更新日期：2026-08-16。

本文原本描述按本地意图路由、用户点选通知/邮件、预投影 `ContextBuilder`、发送前数据披露确认，以及非流式 Provider 的 P4-P5 实现。

该运行时已在 `0.4.6` 删除，不能作为实现、测试或兼容层的依据。THEIA 在 `1.0.0` 前不保留这条旧路径：

- `AdvisorRuntime` 仅创建惰性只读 Agent 工作区；
- renderer 只发送问题，不能提交意图、数据域、通知/邮件选择、正文选择、授权或 `stream: false`；
- 模型自行决定是否、何时以及用哪个固定只读工具查询；
- 每轮调用均要求流式接口并逐 delta 转发，缺少流式能力时直接失败；
- 输出、工具或引用无效时返回可重试错误，绝不拼接本地回退回答；
- 通知和邮件仍只通过 Agent 工具净化后按需读取，且不获得网络、会话、凭据、同步或学校侧写权限。

当前的实现合同、工具列表、输入预算和安全边界见 [内嵌顾问与本地 Agent](20-a-b-c-advisor-agent-sidecar.md)。当前交接与验收入口见 [学业顾问交接](21-advisor-handoff.md)。
