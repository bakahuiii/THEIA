# 新生第一次用 THEIA

北化把不同的事情放在不同系统里。课表在一个地方，作业在另一个地方，邮件又在别处。

THEIA 把这些内容放到一个 Windows 应用里。你不必先记住一堆网址，也不必每次猜应该打开哪个系统。

## 先看懂这些名字

| 名字 | 它是什么 | 里面有什么 |
| --- | --- | --- |
| CAS（统一身份认证） | 学校的登录入口 | 它只负责确认“你是谁”，课表和作业不放在这里。 |
| 教务系统 | 管课程和学业的地方 | 课表、选课、考试、成绩、学分。 |
| 北化在线THEOL | 老师发布课程内容的地方 | 资料、通知、作业、在线测试。 |
| 校园邮箱 | 学校邮件 | 通知、文件和其他邮件。 |
| 体测系统 | 保存体测结果的地方 | 各项体测成绩。 |
| THEIA | 你每天打开的总入口 | 把上面的内容读回来，整理在一起，并帮你完成作业和抢课。 |

一句话记住：**CAS 负责登录，各个系统负责保存不同的内容，THEIA 负责把它们放到一起。**

在 THEIA 里，“同步”就是重新去这些学校系统读取一次最新内容。

## 第一次怎么用

1. 安装并打开 THEIA。
2. 出现“统一身份认证”时，填写学校账号并登录。
3. 点击顶部的“同步”。
4. 同步完成后，先打开“概览”。

“概览”会把今天的课、最近的作业、下一场考试和新通知放在一起。平时不知道先看哪里，就先看这里。

## 什么时候，去哪里，怎么做

| 什么时候 | 你要做什么 | 在 THEIA 哪里 | 怎么做 |
| --- | --- | --- | --- |
| 每天早上 | 看今天的安排 | **概览** | 查看今天的课、地点、作业和下一场考试。 |
| 想看整周或整学期 | 查完整课表 | **课表** | 选择学期和周次。 |
| 老师布置作业或测试后 | 做作业 | **作业** | 打开任务。THEIA 可以整理题目和附件，让 AI 生成草稿或答案，还能把在线测试答案写进页面。你检查后完成最后提交。 |
| 选课开始前 | 准备抢课 | **抢课** | 先同步，再找到课程和教学班，把想选的课加入目标，并设好开始时间。 |
| 选课开放时 | 开始抢课 | **抢课** | 保持 THEIA 和网络开启，点击“开始抢课”。THEIA 会按你的目标自动尝试。 |
| 考试安排发布后 | 查考试 | **考试** | 查看时间、地点和座号。考试前再同步一次。 |
| 成绩发布后 | 查成绩和学分 | **成绩、学业** | 查看成绩、平均成绩、已经完成的课程和还缺的部分。 |
| 想看学校的新消息 | 查通知和邮件 | **概览、通知与邮箱** | 同步课程通知；第一次收校园邮件时，先在“设置与接入”填写邮箱信息。 |
| 体测后或开学时 | 查体测和校历 | **学习工具** | 导入或更新体测成绩，打开校历查看教学时间。 |
| 找不到教室时 | 找教学楼 | **校园地图** | 搜索或查看昌平校区地图。 |

## 抢课第一次要多做一步

北化在线THEOL通过统一身份认证连接；课表、考试和成绩默认也走这一通道。你也可以在“数据”中保存独立的教务系统 API 凭据并启用 API 优先同步。第一次使用抢课时，需要打开：

**设置与接入 → 数据 → 教务系统 API**

把这里理解成“抢课用的教务连接”就行。按页面提示连接一次，再回到“抢课”选择目标课程。

之后最常用的动作只有两个：打开 THEIA，看“概览”；学校有新内容时，点“同步”。
