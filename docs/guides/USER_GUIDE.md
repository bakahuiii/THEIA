# THEIA 用户指南

> 适用对象：北京化工大学学生使用的 Windows 桌面客户端。本文描述已经在 THEIA 中实现的用户功能；它不是开发接口说明，也不替代学校的正式通知、培养方案或教务规定。

THEIA 是一个本地优先的校园工作台。它把课程、课表、成绩、考试、学业进度、北化在线THEOL任务、通知、校园邮箱和一些本地工具放在同一台电脑上。你仍然通过学校的统一身份认证、教务系统、北化在线THEOL和邮箱使用学校服务；THEIA 不创建云端账号，也不替你作出学校系统中的最终决定。

本文按实际使用顺序说明：先连接并同步，再查看和处理各类数据，最后介绍设置、导出、隐私与排障。

## 开始前

### 运行环境

THEIA 运行在 Windows 桌面客户端中，并提供以下本机能力：

- 学校统一身份认证与复用的浏览器会话；
- Windows 加密凭据存储；
- 本地文件选择、课表 PDF 保存、作业工作区和附件下载；
- 校园邮箱 IMAP 收信；
- 教务系统 API 凭据、抢课、体测导入；
- 模型服务 API Key 的安全保存与本地任务处理；
- 完整的数据导出与本机只读数据服务。

首次使用前，请准备好：

1. 可正常登录学校统一身份认证的账号和密码。
2. 网络连接。首次同步需要访问学校教务系统和北化在线THEOL。
3. 若要使用抢课，请准备教务系统账号和密码。它与统一身份认证凭据是两套独立保存的凭据。
4. 若要使用校园邮箱自动收信，请准备学校邮箱账号以及邮箱密码或客户端授权密码。
5. 若要使用模型辅助，请准备一个 OpenAI 兼容服务的地址、API Key 和可用模型 ID。

### 使用边界

THEIA 的重点是整理、读取、准备和辅助，不是无人值守地替你完成学校业务。

| 场景 | THEIA 可以做什么 | 仍由你负责的事 |
| --- | --- | --- |
| 同步 | 读取并整理已授权的校园数据 | 确认账号、网络和学校页面状态 |
| 作业 | 建立本地工作包、生成草稿、打开提交页 | 检查文件并在学校页面完成最终提交 |
| 在线测试 | 准备答案 JSON，并写入内置浏览器中的题目 | 逐题核对并在学校页面点击最终提交 |
| 抢课 | 在你显式启动后，对已锁定目标执行选课请求 | 核对课程、教学班、时间窗口和请求参数 |
| 模型 | 将已准备的本地任务上下文发送给你配置的模型服务 | 判断答案正确性、引用和提交内容 |

不要把计算器结果、模型生成文本或同步结果直接视为学校最终认定。涉及成绩、培养方案、奖学金、体测、选课、学位或处分时，应以学校正式系统与通知为准。

## 第一次启动

### 1. 处理统一身份认证提示

桌面端在没有保存统一身份认证凭据时，会显示“统一身份认证”设置窗口。填写账号和密码，选择“保存并登录”。

- 密码输入框不会回显真实密码。
- 凭据通过当前 Windows 账户的加密能力保存；应用不把它放进导出文件、普通校园数据、本地 API 或诊断日志。
- 保存后，THEIA 会连接教务系统和北化在线THEOL的会话。完成时间取决于学校页面和网络状态。
- 你可以选择“稍后设置”。此时仍能打开界面和查看已有本地数据，但不能首次读取需要认证的数据。

如果曾经保存过账号，THEIA 会在启动后尝试恢复会话。顶部状态区会分别显示“教务系统”和“北化在线THEOL”的连接情况。

### 2. 等待本地快照出现

THEIA 启动时优先读取已存在的本地快照，目的是让上次同步的课表、成绩和任务尽快可用，而不是等待网络请求结束才显示界面。随后它会读取运行状态，例如已连接的数据源、模型配置、邮箱配置、抢课目标和本机服务地址。

这意味着启动时可能先看到旧数据、稍后才看到连接状态变化。这是正常行为。首次安装或本机没有历史数据时，页面会显示空状态，并引导你连接和同步。

### 3. 执行第一次同步

点击顶部工具栏中的同步按钮：

- 尚未连接学校时，这个按钮表示“统一身份认证”，会要求你设置或重新连接账号。
- 已有可用会话时，它表示“立即同步”。

同步期间，顶端会出现进度提示。当前页面不会被清空；旧的课表、成绩和考试会保留显示，新的结果完成后再替换。同步会读取教务系统和北化在线THEOL中可用的项目，包括课程、课表、考试、成绩、已选课程、培养方案/学业进度、通知、作业和在线测试。

首次同步完成后，建议依次检查：

1. **概览**中是否显示当天课程、待办任务、最近考试和通知。
2. **课表**中学期、周次、教师和教室是否合理。
3. **成绩**和**学业**中是否显示已有成绩与培养方案。
4. **作业**中是否出现北化在线THEOL任务。

如果其中一类数据暂缺，不代表所有同步都失败。打开“设置与接入”中的“同步”页，可以查看上次同步的时间、课表/考试/成绩数量和错误摘要。

## 认识工作区

### 侧栏导航

侧栏把常用功能分为三个区域：

| 区域 | 页面 | 用途 |
| --- | --- | --- |
| WORKSPACE | 概览、课表、作业 | 每天最常使用的学习安排和待办 |
| ACADEMIC | 考试、成绩、学业、课程 | 教务信息、成绩记录和培养方案 |
| TOOLS | 抢课、通知与邮箱、学习工具、校园地图、设置与接入 | 校园服务、本地计算器和配置 |

侧栏顶部显示最近更新时间，底部会提示本地数据或部分来源异常。桌面宽屏可收起侧栏；窄窗口中可从顶部菜单按钮打开它。

### 顶部工具栏

页面顶部提供以下常用控制：

- **数据源状态**：分别显示教务系统和北化在线THEOL是否已连接。鼠标悬停可查看状态或错误提示。
- **外观快捷设置**：快速查看或进入完整外观设置。
- **同步/登录按钮**：已连接时立即同步；未连接时进入统一身份认证流程。
- **个人状态**：显示姓名首字或默认图标，以及当前登录/未登录状态。
- **课程搜索框**：只在“课程”页面显示，可按课程名、课程代码或教师筛选。

按 `Ctrl+K` 可以打开“快速跳转”，输入页面名称后直接进入相应页面；按 `Esc` 关闭快速跳转。

### 空状态不是故障

THEIA 会在没有可显示数据时明确告诉你原因。例如“连接教务系统并同步后即可查看”“该学期没有考试记录”或“北化在线THEOL中未发现未提交任务”。先按提示判断是未同步、筛选条件不匹配，还是学校源本来没有数据，再决定是否排障。

## 同步与数据更新

### 手动同步

手动同步适合这些场景：

- 刚完成统一身份认证；
- 学校刚发布成绩、考试、通知或北化在线THEOL任务；
- 课表、已选课程或培养方案发生变化；
- 需要在导出前刷新本地数据。

同步并不是把所有旧数据立即删除。THEIA 会在学校某个页面临时失败时尽量保留已有的有效本地结果，避免一次短暂网络异常导致成绩或课表突然消失。因此，看到“部分数据源未连接”时，应先重试或检查错误摘要，不必立刻手动清理本地文件。

### 后台定时同步

在“设置与接入”打开“同步”，可以启用“后台定时同步”并设置间隔。

- 间隔最短为 **5 分钟**，用于避免频繁请求学校系统。
- 后台同步只在 THEIA 桌面客户端运行时工作；关闭应用后不会在后台常驻。
- 同步期间仍可浏览上一次成功结果，顶部会显示当前读取阶段。

### 数据来源的角色

THEIA 把不同学校系统的数据分开处理：

| 数据来源 | 通常提供的数据 |
| --- | --- |
| 教务系统 | 课程、课表、考试、成绩、已选课程、培养方案/学业进度、教务通知、选课相关信息 |
| 北化在线THEOL | 课程、作业、在线测试、通知、课程资料关联 |
| 体测系统 | 体测成绩，仅在你主动导入或更新时读取 |
| 校园邮箱 IMAP | 收件箱元数据，正文和附件按需读取 |

教务数据默认使用统一身份认证页面读取；也可以在设置中启用可选的“教务系统 API 优先”通道。API 通道成功时优先读取。若 API 未启用或没有保存 API 凭据，THEIA 使用统一认证页面通道；若已启用的 API 通道本次请求失败，THEIA 会保留已有本地数据并显示来源错误，不会在同一轮同步中静默切换到浏览器通道。北化在线THEOL仍使用其独立的会话。

一次同步分为可见的主同步和后续任务扫描。教务高优先领域可按适配器策略并发读取，北化在线THEOL首页也与教务主同步并行启动。主同步完成并发布快照后，北化在线THEOL逐课程 `Course task` 扫描会在后台静默启动；它使用 THEOL 独占队列并逐课程严格串行，因此作业列表可能在主同步进度结束后稍晚更新。

## 校园概览

“概览”是当天学习信息的集中入口，不是另一份独立数据。它使用本地快照中的课表、考试、任务和通知进行汇总。

### 快速访问与指标

顶部的快速访问可进入本周课表、考试安排、成绩与 GPA、校园地图。指标条会显示：

- 课程数量；
- 未提交且未超过截止时间的任务数量；
- 已同步的考试记录数；
- 已同步的成绩记录数。

点击指标会进入对应的详细页面。

### 今天的课程

概览会按当前星期、校历学期和周次筛选今天的课程。校历已知时，只有符合当前学期和周次的课程才会显示；校历尚未提供时，页面会以已有课表为准。课程卡显示节次、课程名、教师、教室和周次。

### 下一场考试

“下一场考试”会从已同步考试中寻找未来时间最近的一场，显示日期、课程、时间、校区、地点和座号。没有未来考试时会显示空状态，不会猜测考试安排。

### 待办作业与通知

概览中的待办任务按截止时间排序，且会排除已经过期的未提交任务。通知列表来自教务系统和北化在线THEOL；点击可进入“通知与邮箱”查看详情。

## 课表、考试、成绩与学业

### 课表

进入“课表”后，可以按以下方式查看：

1. 使用“今日课表”回到校历识别出的当前周。
2. 通过学期选择器切换要查看的学年/学期。
3. 在“按周”和“全学期”之间切换。
4. 在“按周”模式输入周次。
5. 点击任一课程格查看课程详情，包括周次、教师和教室。

如果同一节次有多门课程，格子会显示叠加标记，点击后可逐条查看。没有可解析节次或星期的信息会出现在“节次待定”区域，而不是被静默丢弃。

#### 课表 PDF

右上角“输出 PDF”调用教务系统原生的课表 PDF 输出流程。THEIA 会在内置学校页面中打开课表、请求原系统生成 PDF，并默认保存到 Windows“文档”目录下的 `THEIA/课表` 文件夹。

这依赖教务会话和学校原页面的“输出 PDF”功能。如果导出失败，请先确认教务系统已连接，再重新同步或重新登录后重试；它不是通过界面截图生成的替代 PDF。

### 考试

“考试”支持两类筛选：

- 按学期查看；
- 在“全部安排”和“仅未来考试”之间切换。

列表会把有明确时间的考试按时间排序。过去的考试会有已过期状态。每条记录可包含考试类型、方式、校区、地点、座号和备注；学校尚未发布的信息会显示“待公布”，而不是通过其他字段推断。

### 成绩与 GPA

“成绩”由成绩趋势、汇总和明细构成：

- 可按学期筛选记录；
- GPA 图表可在“阶段”和“累计”口径之间切换；
- 汇总显示总 GPA、本学期 GPA（选择单个学期时）、成绩记录数和已获得学分；挂科、缺考与不合格课程不计入已获得学分，同一课程重修通过后只计一次学分；
- 明细显示课程、代码、性质、学分、成绩、绩点、备注和教师。

GPA 只使用符合现有计算规则的记录。标注为“不统计”的项目不会被当作普通 GPA 项目；同一课程存在多次成绩时，本地辅助计算按课程代码选取最高绩点一次，补考、重修、缺考等备注仍保留学校原始语义。结果用于辅助查看，正式成绩以教务系统为准。

### 学业进度

“学业”优先展示教务系统提供的培养方案与课程层级，包括：

- 教务 GPA；
- 计划内已通过课程数；
- 当前在读数；
- 未通过数；
- 培养方案的主类目、子类目、要求学分、已获学分和课程明细；
- 当前学期已选课程的学分、类别、教师、时间和地点。

如果学校未提供培养方案层级，页面会明确标注“成绩归类”，仅按已同步成绩组织已修课程。这种降级展示不能替代正式培养方案，也不应据此单独判断毕业资格。

## 课程与抢课

### 我的课程

“课程”页面仅展示北化在线THEOL课程。可使用：

- 顶部搜索框：搜索课程名、课程代码或教师；
- 学期筛选：查看课程在哪些学期出现；
- 课程类别筛选：缩小到某一课程类型。

课程卡会显示课程代码、来源、教师、学分、类别、地点和来源学期。北化在线THEOL通常只提供活动课程名单，因此在没有其它关联学期信息时，THEIA 会以当前教学学期作为展示依据。底层本地快照仍可保留教务课程供课表、成绩、考试、学业与接口使用，但这些教务课程不会出现在“课程”页面。

### 抢课前必须完成的准备

抢课会向学校系统发送选课请求。请只在你明确要操作的课程、教学班和时间窗口已核对无误时启动。THEIA 不自动执行退课、评教或其它学校业务。

抢课页面需要当前学期信息，因此首次使用前先完成至少一次教务同步。它还需要单独的教务系统 API 凭据：

1. 打开“设置与接入” -> “数据与接口”。
2. 在“教务系统 API”区域保存教务系统账号和密码。
3. 打开“启用 API 优先”。
4. 回到“抢课”，再读取选课批次或全校课表。

这套 API 会话与统一身份认证会话隔离保存，不会把 Cookie 混用。若没有启用 API 或没有保存 API 凭据，抢课页面会提示配置问题，而不会悄悄使用另一套账号或模拟浏览器提交。

### 推荐的抢课流程

1. 在页面下方“全校课表”选择学期，点击“读取本学期课表”。
2. 使用课程关键字、院系、教师、课程类型等筛选条件缩小结果。表格支持排序。
3. 在希望的教学班行点击“设为目标”。目标会保存在本机的抢课计划中。
4. 在页面上方点击“读取选课批次”。如果批次尚未开放，仍可继续保存目标，等待开放后再读取。
5. 如有开放批次，可选择课程类别/选课模块并读取教学班，核对教师、时间地点、余量和学分。
6. 设置开始时间、结束时间、重试间隔、最大尝试次数和并发任务数。页面允许并发任务，但会限制在较小范围内。
7. 点击“开始抢课”。每一个已锁定目标会作为独立任务执行，日志会显示时间、课程和实际调用结果。
8. 成功、无余量、超出结束时间或达到尝试次数后，查看任务状态和日志；必要时点击“停止全部任务”。

在“抢课计划”里可随时移除还未执行的目标。开始任务前再次检查课程代码、教学班、教师、时间和地点，尤其是在课程名相近或同一门课有多个班时。

### 选课时间与哨兵

若校历中的教学进程已经识别出选课窗口，可使用“自动获取选课时间”填入开始和结束时间。它只是从本地校历分析结果取值；学校实际开放状态仍以选课门户返回的状态为准。

“开启哨兵”会保存目标和时间窗口。THEIA 在运行时会在窗口内执行已配置的目标；应用在有效窗口内重新启动时，也会尝试恢复已开启的哨兵任务。它不是云端守护服务：电脑关机、网络断开或应用没有运行时，无法发出选课请求。

对于普通抢课任务，关闭应用、会话失效或学校门户变化都可能中断执行。THEIA 会记录本机状态摘要，但不保证跨重启继续一个未启用哨兵的普通任务。

## 作业、在线测试与模型辅助

### 作业列表

“作业”汇总北化在线THEOL中的任务和在线测试。上方可切换：

- **待完成**：未提交任务；
- **已提交**：平台标为已提交的任务；
- **全部**：两者合并。

已经超过截止时间的未提交任务会自动从列表中隐藏，避免过期任务长期占据待办视图。每个任务显示课程、类型、截止时间、状态，以及已有本地工作包的题目和附件数量。

### 建立本地工作包

对尚未提交的任务点击“准备工作包”。THEIA 会在本地受控工作区准备任务材料，包括：

- 任务题干；
- 可读取的附件；
- 在线测试解析出的题目；
- 清单文件和所需模板；
- 后续导入的答案文件、模型结果或 PDF。

点击“打开工作区”可以检查这些本地文件。先阅读题干、课程要求、附件和格式要求，再考虑模型辅助或提交。重新准备会更新本地任务材料，因此应在替换前确认你想保留的个人修改。

### 配置并使用模型服务

模型功能是可选的。进入“设置与接入” -> “模型服务”，依次填写：

1. OpenAI 兼容服务地址；
2. API Key；
3. 模型 ID。

填写地址和 API Key 后，THEIA 会尝试读取兼容服务的模型列表，并自动选择一个推荐的文本模型。若服务不提供模型列表或探测失败，仍可手动填写模型 ID。保存前请确认服务地址是你信任的服务。

模型 API Key 与校园账号分开保存，且不会进入校园数据、导出文件、本地 API 或诊断日志。调用模型时，THEIA 只发送已准备的本地任务上下文；学校密码、Cookie、浏览器存储和已认证页面不会发送给模型服务。

### 普通作业流程

推荐顺序如下：

1. 先点击“准备工作包”。
2. 在本地工作区检查题干和附件。
3. 点击“生成答案”，将结果写入本地工作区。
4. 对普通作业，还可生成“笔记”或“论文”草稿。
5. 用“答案→PDF”“笔记→PDF”或“论文→PDF”将相应 Markdown 结果渲染为 PDF，再用“打开 PDF”检查。
6. 点击“选择文件并提交”打开北化在线THEOL提交页，选择你确认过的文件。
7. 在学校页面自行检查内容并完成最终提交。

模型输出是草稿，不保证事实、计算、引用、格式或课程要求正确。尤其是实验报告、代码、论文、设计作业和涉及学术诚信的内容，必须由你核查和改写。

### 在线测试流程

在线测试与普通作业不同：

1. 点击“准备工作包”，确认本地题目数量和内容。
2. 通过模型生成答案，或点击“导入答案 JSON”导入你准备的结构化答案。
3. 点击“写入测试页”。THEIA 会尝试将通过格式检查的答案写入内置浏览器中的测试页面。
4. 逐题检查写入数量和未匹配题目提示。
5. 在学校测试页由你自己完成最终提交。

THEIA 不点击学校在线测试的最终提交按钮。若出现“已写入 X/Y 题”，不要直接假设未写入的题无关紧要；应在测试页面逐题核对。

## 通知与校园邮箱

### 通知

“通知与邮箱”采用左右两个独立区域：校园邮箱和通知。通知来自教务系统与北化在线THEOL，可按标题、来源或摘要搜索。点击通知可查看来源、发布时间、本机记录 ID 和可用摘要。

通知详情目前展示的是同步到本机的摘要，不应把它理解为完整原公告正文。需要原始上下文时，使用任务或课程中的“打开原站/查看原题”入口，或者回到学校系统核实。

### 设置校园邮箱

打开“设置与接入” -> “数据与接口”中的“校园邮箱”，可配置：

- 邮箱账号；
- 邮箱密码；
- 可选的客户端授权密码；
- 后台收信开关；
- 检查间隔，最短 1 分钟。

学校邮箱若拒绝普通登录密码，可在网页邮箱旧版设置中生成客户端授权密码；保存后，THEIA 会优先使用授权密码。网页邮箱按钮仅用于手动打开网页或处理客户端协议设置，常规收信使用 IMAP。

开启后台收信后，THEIA 按设定间隔读取收件箱列表。首次配置后也可点击“立即收信”。邮箱密码和授权密码同样由当前 Windows 账户加密保存，不会出现在导出、本地 API 或诊断日志里。

### 阅读邮件与下载附件

邮件区可按发件人、主题或摘要搜索。列表显示未读状态、接收时间和附件数量。打开邮件时：

- 正文按需从邮箱读取并在隔离阅读区域中显示；
- 可点击“重新载入”重新读取和渲染原邮件；
- 附件需要逐个点击“下载”，并由你选择保存位置；
- 邮件 HTML 会经过安全处理，动态脚本、表单和危险内容不会在阅读区执行。

邮件列表、已读取正文和下载动作均以本机使用为目的。请勿把包含个人或学校敏感信息的邮件随意导出或转交第三方模型服务。

## 学习工具与校园地图

### 校历与教学进程

“学习工具”的默认页是“校历”。THEIA 会在启动时检查并把校历、教学进程表和周历保存到本地数据目录。页面可显示：

- 当前学年和已识别学期日期；
- 当前周；
- 高清校历图；
- 教学进程表与周历的本地 PDF 预览。

点击“立即更新”可以手动刷新。出现“校历已保存，但日期识别失败”时，说明原始资料已经取得，但自动读取日期没有成功；此时可以直接查看资料，课表“今日”定位和选课时间自动填充可能无法使用或不完整。

### 体测评分

“体测评分”支持两种来源：

- **导入体测档案/更新体测档案**：主动读取学校体测系统并保存本地年度档案；
- **局部输入计算**：在没有已导入档案时，填写身高、体重、肺活量、跑步等项目进行本地估算。

首次导入后可以在测试年份选择器中离线切换已有年度。已导入的原始结果在界面中保持只读，避免本地计算表单误改档案。体测标准和成绩认定仍以学校系统为准。

### 学业预警

“学业预警”是手工输入式计算器。你可以输入当前 GPA、必修课总学分和已获学分，查看界面中实现的 GPA 阈值和升学学分比例提示。它不会自动修改你的培养方案，也不等同于学校实际作出的学籍、退学或学位决定。

### 创新学分

“创新学分”用于估算创新创业类课程与实践学分：

- 手动填入已修课程学分；
- 选择已经获得认定的实践项目；
- 对可按次数累计的项目调整次数；
- 查看课程、实践和总计是否达到页面列出的门槛。

这里的项目和分值只是本地计算输入。最终认定时间、材料和分值必须以学院/学校的正式规则为准。

### 第二课堂

“第二课堂”按五个维度输入分数，并将每项限制在其页面上显示的上限内。它可显示总分、各维度是否达到 60% 门槛，以及基于输入的奖学金综合成绩估算和推免公式提示。所有输入仅存在当前页面会话中，不能代替第二课堂系统的正式成绩。

### 校园地图

“校园地图”提供北京化工大学昌平校区的高分辨率校园总图和对齐的卫星底图。

- 使用鼠标滚轮缩放；
- 拖动地图平移；
- 双击可放大；
- `+` / `=` 放大，`-` 缩小，`0` 回到全图；
- 右侧按钮可切换校园总图和卫星底图，或执行放大、缩小、查看全图。

当前地图用于查看昌平校区整体位置和教学地点环境，不提供室内导航、步行路线规划或实时定位。图层、缩放和位置会保存在这台设备的本地偏好中。

## 设置、数据来源与导出

“设置与接入”是一个独立的设置窗口，分为“外观”“同步”“数据与接口”“模型服务”和“关于”。

### 同步

这里可以：

- 开关后台定时同步；
- 设置同步间隔；
- 点击“立即全量同步”；
- 查看上次同步时间、课表读取结果、错误摘要，以及课表/考试/成绩数量。

同步错误只显示用于排障的来源、阶段、HTTP 状态、耗时或简要错误信息，不应包含你的密码、Cookie 或 API Key。

### 数据与接口

该页集中管理：

- 统一身份认证账号；
- 可选的教务系统 API 优先通道；
- 校园邮箱 IMAP；
- 本机活动记录；
- THEIA 本机只读数据接口；
- 文件导出。

“本机活动记录”便于判断何时发生同步、读取或错误。它只记录安全的操作元数据，不记录账号、密码、Cookie 或模型 API Key。

本机数据接口只监听本机回环地址，默认端口为 `8765`，实际端口会显示在设置中。它是为本机脚本、个人工具或同机应用准备的只读接口，不是面向互联网公开的服务。接口字段和使用方式请看相应的数据接口文档；普通用户不需要为日常使用手动访问它。

### 导出

在“数据与接口”下方的“导出”区域，可选择保存位置并生成以下文件：

| 导出项 | 用途 |
| --- | --- |
| 导出给 AI | 生成经净化、带说明与 SHA-256 校验清单的完整离线学业上下文包 |
| 完整 JSON | 备份当前完整本地校园快照 |
| THEIA Data Feed | 供其他本地工具离线消费的事件、任务和学业数据视图 |
| 日历 ICS | 导入日历软件的考试和作业截止时间 |
| 成绩 CSV | 在表格软件中查看和统计成绩 |

选择“导出给 AI”后，先选择一个**父文件夹**。THEIA 会在其中新建一个时间戳命名的 `THEIA-AI-EXPORT-...` 文件夹，不会覆盖此前的导出。这个文件夹内有 `AI_CONTEXT.md`、`DATA_DICTIONARY.md`、`manifest.json` 和按领域拆分的 JSON；`manifest.json` 列出其余 18 个文件的 SHA-256，交给 AI 或本地工具前可先检查它们没有损坏。它不会自动上传或调用你配置的模型服务。

导出前最好先手动同步。导出包含的是当时已有的本地快照，不会在保存文件时自动重新登录学校系统。AI 包不包含学校密码、邮箱授权码、模型 API Key、Cookie、浏览器会话、原始附件或本机绝对路径，但仍可能含有姓名、学号、课程、成绩、任务、通知、邮件文本、附件名称、体测和校历等个人信息。只把它交给你明确选择并信任的服务或工具；AI 包是分析快照，不能代替学校系统中的选课、提交或实时确认。

### 关于

“关于”页显示 THEIA 的版本、数据格式标识、本机接口地址和当前本地工作区状态。它用于确认客户端当前状态，不是学校官方公告页面。

## 外观与背景

### 基础主题与缩放

在“外观”中可选基础主题：

- **Classic**：平衡、清透的基础界面；
- **Midnight**：深色基础界面；
- **主题模式**：浅色、深色或跟随系统。

桌面端还可选择界面缩放档位。缩放改变工作区显示比例，不影响实际校园数据或导出内容。

### 一体化外观预设

一体化预设会同时调整基础主题、界面色板、双色映射和背景效果；它不会把你的自定义图片替换成其它图片，除非预设本身指定了内置背景。

预设分为两层：

- **古典**：内置的金属色调系列；
- **北化风情**：一个面向用户的镜湖四时预设。

你还可将当前外观保存为个人预设。个人预设保存在本机，最多可保存 16 套；它们不会覆盖内置预设。

### 北化风情与节气切换

“北化风情”在界面中只显示为一个选项，不要求你手动从多张湖景中挑选。选择后会先使用“柳湖”作为基础背景；当 THEIA 的首次运行状态读取结束后，客户端会根据中国标准时间的节气切换到相应的镜湖季节图：

| 起始节气 | 使用季节 |
| --- | --- |
| 立春起 | 春 |
| 立夏起 | 夏 |
| 立秋起 | 秋 |
| 立冬起 | 冬 |

例如，日期已经过立秋时，会使用秋景，而不是按自然月把整个八月简单归为夏天。节气判断在本机完成，不需要为了切换背景发起网络请求。

北化风情默认保留原图质感：图像强度为 100%，面板透明度为 50%，并使用从当前图片采样出的克制界面色板。它的目的不是把内容页面做成纯图片，而是在保证文字与表格可读的前提下保留校园背景。

### 自定义背景、色板与效果

在“选择图片”中可选择本地 PNG、JPG、WebP、GIF 或 AVIF 图片。桌面端会把选中的文件复制到 THEIA 的本地背景目录，界面不会暴露你的任意原始文件路径。选中图片后可进行以下调整：

- **双色映射**：分别设定暗部和亮部颜色、映射位置，并选择是否应用到背景；
- **同步界面色板**：在本地从背景照片采样主色和辅助色，为当前浅色/深色模式生成保持可读性的界面色板；
- **原图模糊**、**面板透明度**、**图像强度**、**亮度**、**对比度**、**饱和度**；
- **图片纹理**和纹理覆盖高度；
- **鼠标视差**、视差幅度和背景缩放。

“同步界面色板”只在本地分析当前背景，不上传图片。关闭它后，界面回到预设或手动指定的色板；关闭“应用到背景”后，双色映射不会改写背景图的明暗两端。

如果阅读困难，优先降低面板透明度、降低图像强度或关闭纹理/鼠标视差，再选择浅色或深色主题。点击“移除图片”可恢复纯净工作界面。

## 本地数据与隐私

### 数据保存位置

THEIA 默认将持久数据保存到当前 Windows 用户的应用数据目录 `%APPDATA%\THEIA`。这包括规范化校园快照、课表和校历资料、本地课程工作区、邮件缓存、已保存的外观偏好和安全诊断信息。

对于管理员或自动化环境，可通过 `THEIA_DATA_ROOT` 指定数据根目录。普通用户不建议手动移动、编辑或删除内部数据文件；需要备份时使用设置页的导出功能。

### 哪些内容不会进入导出或普通数据

THEIA 将敏感凭据与业务数据分离保存。以下内容不会进入校园快照、导出文件、本机数据接口、任务清单或普通诊断日志：

- 学校统一身份认证密码；
- 教务系统 API 密码；
- 校园邮箱密码和客户端授权密码；
- 模型服务 API Key；
- 浏览器 Cookie、浏览器存储和已认证会话；
- 原始学校页面及不受控的二进制邮件附件。

凭据由 Electron 的安全存储与 Windows DPAPI 保护，通常只能由保存它们的当前 Windows 账户解密。更换 Windows 账户、重装系统安全环境或手动复制应用数据目录后，可能需要重新输入凭据。

### 模型服务的隐私边界

只有在你配置模型服务并主动对已准备任务点击生成时，THEIA 才会向该服务发送请求。发送内容是本地工作包中的任务上下文，例如题干、可读取附件文本和测试题目；不会包含学校密码、Cookie、浏览器会话或完整已认证页面。

你仍应评估模型服务自己的隐私政策和数据处理地点。对于包含个人信息、同学信息、未公开课程材料或敏感研究资料的附件，先决定是否适合发送给该服务。

### 本机接口的边界

THEIA 运行时提供的本机数据服务仅监听 `127.0.0.1`，即同一台电脑。它是只读服务，不会提供写入校园数据、代替网页登录或公开访问的能力。不要通过端口转发、反向代理或防火墙规则把它主动暴露到局域网或互联网。

## 常见问题与排障

### 启动后没有数据

先区分两种情况：

1. **首次启动**：本机还没有快照。设置统一身份认证后点击同步即可。
2. **以前有数据但现在为空或不完整**：检查顶部两个数据源状态，进入“设置与接入” -> “同步”查看上次同步时间和错误摘要。

不要为了解决单次同步错误而直接删除 `%APPDATA%\THEIA`。THEIA 设计为在暂时错误时保留旧快照；直接删除会失去本地课程工作区、邮件缓存、外观和恢复信息。

### 顶部显示“部分数据源未连接”

这表示教务系统和北化在线THEOL中至少有一个会话没有验证成功。可按下面顺序处理：

1. 检查网络和学校服务本身是否可访问。
2. 点击顶部登录/同步按钮，重新连接统一身份认证。
3. 确认账号密码没有更改或过期。
4. 返回同步页查看哪个来源报错。
5. 重新同步，确认已有本地数据没有被误认为是最新数据。

即使只有一个来源连接，另一来源已有的数据仍可能继续留在本地；不要仅凭一个状态点判断所有课程信息失效。

### 点击同步却一直是旧数据

同步期间页面会保留旧数据，直到新的阶段完成才替换。等待顶部进度提示结束，然后：

- 在同步设置中核对“上次同步”时间是否改变；
- 查看课表、考试、成绩数量是否有更新；
- 检查是否使用了学期筛选，导致新数据不在当前视图内；
- 打开活动记录查看最近的本地读取和错误摘要。

如果学校源返回空数据，页面可能显示“空（服务端无数据）”。这与网络失败不同，通常需要去原学校页面确认该学期是否确实尚未发布。

### 课表“今日课表”不正确或提示校历未知

“今日课表”依赖本地校历识别出的学期和周次。请进入“学习工具” -> “校历与教学进程”：

1. 点击“立即更新”。
2. 查看校历是否已下载。
3. 若显示日期识别失败，先查看原始校历资料，并在课表页手动选择学期和周次。

在假期内，“今日课表”会提示当前假期而不是硬套某个教学周。

### 课表 PDF 导出失败

该功能需要教务系统的已验证会话和原页面的 PDF 输出功能。建议：

1. 重新连接教务系统；
2. 从课表页确认已有课程可显示；
3. 再点击“输出 PDF”；
4. 若学校页面本身变化或无法加载，稍后重试，并用活动记录中的时间和错误摘要定位问题。

### 抢课页面提示没有批次、无法读全校课表或不能开始

依次检查：

1. 是否完成过教务同步，当前学期是否存在；
2. 是否已在“数据与接口”保存教务系统 API 账号和密码；
3. 是否已打开“启用 API 优先”；
4. 是否已经从全校课表把至少一门课设为目标；
5. 是否已经读取选课批次；
6. 开始时间和结束时间是否合理，结束时间必须晚于开始时间；
7. 学校选课批次是否实际开放。

“当前没有开放的选课批次”并不阻止你提前锁定目标。不要在门户未开放时把大量快速重试当作有效策略；页面会把门户未开放情况单独记录并延后探测。

### 邮箱收不到或无法打开正文

检查邮箱设置中的账号、密码/授权密码、后台收信开关和检查间隔。若普通邮箱密码被拒绝：

1. 通过“打开网页邮箱”进入学校邮箱；
2. 在学校支持的位置启用客户端协议或生成授权密码；
3. 在 THEIA 中填写授权密码并保存；
4. 点击“立即收信”。

邮件正文只在打开时按需读取。列表已经出现但正文报错时，可在邮件详情中点击“重新载入”。附件也需要手动点击下载，邮件列表本身不会把附件二进制数据全部保存到主状态。

### 模型列表检测不到，或“生成答案”不可用

确认以下项目：

1. 服务地址是否是 OpenAI 兼容的地址，通常包含正确的版本路径；
2. API Key 是否已保存；
3. 模型服务是否允许读取模型列表；
4. 是否已选择或手动填写模型 ID；
5. 对应任务是否已经“准备工作包”。

模型列表探测失败时，若服务支持聊天补全但不公开模型列表，可以手动输入模型 ID 后保存。生成按钮仍然要求模型配置完整。不要把网络或服务商错误归因于校园账号。

### 背景太暗、太花或文字难读

进入“外观” -> “背景效果”，按优先级调整：

1. 降低“面板透明度”；
2. 降低“图像强度”；
3. 降低对比度、饱和度或关闭图片纹理；
4. 关闭鼠标视差；
5. 切换浅色/深色主题或关闭“同步界面色板”；
6. 必要时移除背景图片。

北化风情的默认值是保留原图的 100% 图像强度与 50% 面板透明度；若你的显示器或环境光导致阅读困难，可以按个人偏好调低，而不会影响数据。

### 导出文件没有刚才的新数据

导出只保存当前本地快照。先手动同步，确认同步完成时间和页面数据已更新，再进入“数据与接口”执行导出。保存时也要确认选中的目录和文件名；THEIA 不会把导出自动上传或替你覆盖任意文件。

### 需要向他人报告问题

请提供以下非敏感信息：

- THEIA 版本；
- 大致发生时间；
- 所在页面和执行的操作；
- 顶部数据源状态；
- 同步页或活动记录中已脱敏的错误摘要；
- Windows 版本和安装方式。

不要发送密码、Cookie、完整 API Key、完整导出文件或含个人信息的邮件附件。THEIA 的活动记录设计为不含这些内容。

## 日常使用建议

### 每日

1. 启动 THEIA，确认顶部数据源状态。
2. 在概览查看今天课程、待办和下一场考试。
3. 有新通知或北化在线THEOL任务时执行一次同步。
4. 处理作业前先准备并检查本地工作包。

### 每周

1. 在课表中确认当前周和下周安排。
2. 在考试页切换到“仅未来考试”。
3. 在作业页处理临近截止时间的任务。
4. 需要时更新校历或体测档案。

### 重要操作前

在抢课、提交作业、写入在线测试、发送模型请求和导出完整数据之前，停下来检查以下事项：

- 当前账号、课程、教学班和学期是否正确；
- 学校页面中的时间、地点、容量和截止时间是否与界面一致；
- 任务附件、模型文本或答案 JSON 是否经过人工检查；
- 导出目的地和接收方是否可信；
- 是否理解该操作会不会向学校系统或模型服务发出请求。

THEIA 的价值在于让校园数据和本地工作流更清晰，而不是消除你对重要操作的判断与确认。
