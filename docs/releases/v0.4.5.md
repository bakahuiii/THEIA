# THEIA v0.4.5

## Agent 上下文与读取链优化

- 首轮只发送有界的 Agent session inventory；后续模型请求使用 `theia-advisor-agent-anchor/v1`，不重复发送完整清单或历史 transcript。
- 线程上下文只保留最近的用户导航提示、claim/reference ID 和极短摘要，且明确标记为非事实来源；当前事实必须重新通过本地只读工具读取。
- 工具观察统一做结构化压缩，保留数据健康、通知摘要/发布时间、邮件元数据/正文片段、截止时间、风险和引用 ID，同时设置 24 KB 观察上限并显式标记截断。
- 本地读取按关注域和关键词排序，支持有界 offset；健康查询支持按域读取，避免为了一个问题扫描并披露整套校园数据。
- Agent 系统契约要求事实问题先做最小本地查询，禁止重复 lookup、整段 transcript 复制和把截断当成空数据。
- 保持原有只读权限、快照版本绑定、敏感字段清洗和 `CitationVerifier` 证据校验。
