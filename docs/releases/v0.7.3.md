# THEIA v0.7.3

> 状态：改进 COS 自动更新交互，保留 GitHub/Gitee 代码镜像和 GitHub 发行存档。

## 变更

- 正式 Windows 安装包启动时继续自动检查 COS 更新，但发现新版本后由用户点击“更新”才开始下载。
- 右下角更新通知通过 Portal 固定到应用视口，不再随页面滚动。
- 新版本通知提供“更新”和“跳过版本”按钮；跳过版本会保存在本机，后续新版本仍会正常提示。
- 关于页的更新进度旁显示安装包实际文件大小，并用下载事件的总大小校正显示。
