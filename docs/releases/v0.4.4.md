# THEIA v0.4.4

## Agent 输入预算与空结果修复

- 限制只读 Agent 默认最多 3 个工具步，并设置累计 8,000 token / 128,000 byte 输入预算。
- 工具调用后的模型上下文只携带当前观察与有界证据索引，不再重复发送完整 transcript。
- 证据索引保留已披露的 claim/reference ID，跨多个只读工具仍可完成引用校验。
- 合法但全空的 narrative 会安全回退到本地已披露事实、未验证来源提示，或明确的无匹配记录说明。
- 回退结果继续经过 `CitationVerifier`；不扩大网络、浏览器、凭据或写操作权限。
