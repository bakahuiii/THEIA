# THEIA v0.7.2

> 状态：将 Windows 自动更新源切换为腾讯云 COS，保留 GitHub/Gitee 代码镜像和 GitHub 发行存档。

## 本次更新

- 正式 Windows 安装包通过 `electron-updater` 的 `generic` provider 从 COS `stable/` 目录检查和下载更新。
- 自动更新界面明确显示 COS 更新服务，避免把校园网对 GitHub 的连通性误认为更新服务状态。
- 保留 GitHub 作为源码和发行存档，Gitee 作为代码镜像。

## 兼容与边界

- 仅正式 Windows 安装包支持自动更新；浏览器预览和开发模式不支持。
- COS 桶保持“公有读、私有写”，客户端只访问公开更新文件。
- 安装包未配置可公开验证的 Authenticode 证书，Windows 可能显示未知发布者或 SmartScreen 提示。
