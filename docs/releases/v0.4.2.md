# THEIA v0.4.2

## 中文

### 重点更新

- 学业顾问加入本地数据质量、学业风险、日程、课程决策、证据追溯和显式披露控制；模型调用仍由用户自行配置，并只在用户确认的范围内使用本地数据。
- 学业数据、统一认证浏览器会话和可选教务 API 的失败恢复及数据来源标记得到补强，保留本地优先与只读边界。
- 安装包增加离线冒烟验证；源码归档通过清单校验，排除凭据、Cookie、运行期缓存、诊断和实验抓取脚本。
- 项目采用 MIT 许可证，并补充安全报告与分发兼容性说明。

### 发布文件

- `THEIA-0.4.2-x64-win.exe`: Windows x64 安装包。
- `THEIA-0.4.2-source.zip`: 可复现、带清单的源码归档。

### 安全与验证

- 本版本没有可公开验证的 Authenticode 签名。Windows 可能显示未知发布者提示；请仅从官方 Release 下载，并校验 Release 中公布的 SHA-256。
- MIT 仅适用于 THEIA 的源代码，不授权学校服务、第三方商标或用户数据。
- THEIA 不是学校官方系统，任何课程、考试、选课或作业信息均应以学校系统为准。

## English

### Highlights

- Academic Advisor adds local data quality, academic risk, agenda, course-decision, evidence-traceability, and explicit disclosure controls. Model use remains user-configured and limited to user-approved local context.
- Recovery and provenance for academic data, browser SSO sessions, and the optional academic API are strengthened while retaining local-first, read-only boundaries.
- The installer receives offline smoke coverage. The source archive is manifest-verified and excludes credentials, cookies, runtime caches, diagnostics, and experimental crawlers.
- THEIA is released under the MIT License with security-reporting and distribution-compatibility documentation.

### Release Files

- `THEIA-0.4.2-x64-win.exe`: Windows x64 installer.
- `THEIA-0.4.2-source.zip`: manifest-backed reproducible source archive.

### Security and Verification

- This release has no publicly verifiable Authenticode signature. Windows may show an unknown-publisher prompt; download only from the official Release and verify the published SHA-256 values.
- MIT covers THEIA source code only. It does not grant rights to school services, third-party trademarks, or user data.
- THEIA is not an official university system. Verify all course, exam, enrollment, and assignment information with the school system.
