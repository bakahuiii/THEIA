# THEIA v0.4.6

## Agent 数据流收敛

- 删除 `AdvisorRuntime` 中不可达的 P4-P5 预投影、词法检索、用户范围选择、旧 Provider 发送和本地格式回退路径。
- 仅保留惰性只读 Agent：首包仅含问题与冻结 revision，模型自行按需调用固定工具。
- 移除首包中的本地意图和空领域元数据；不再根据问题进行本地数据域分类。
- 每一轮模型调用均要求 `generateStream()` 并逐 delta 转发；请求中的 `stream: false` 不能关闭该行为，Provider 不支持流式时直接失败。
- 无效工具调用、无效引用、无效叙述或空结果返回可重试错误，不再生成“未确定”或“没有匹配记录”的本地回答。
- 版本同步至包、MCP bridge、数据模型示例、导出契约及回归测试。
