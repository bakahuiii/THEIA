# THEIA v0.6.3

## 本次更新

### 自动更新可视化

- 顶部新增自动更新状态提示，覆盖检查中、发现更新、下载中、已下载和错误状态。
- 下载中显示百分比、已传输大小、总大小和传输速度；无法计算进度时显示稳定的进行中状态。
- “关于”页面复用同一份更新状态和进度，不再与顶部提示各自读取、各自显示。
- 当前版本缺少 `latest.yml` 时按“暂无更新”处理；发现更高版本但发布物不完整时仍明确显示错误，避免掩盖发布问题。

### 登录与凭据恢复

- 保存或修改学校凭据后，登录入口等待完整的统一身份认证生命周期，再刷新校园数据。
- 认证未完成或失败时返回明确错误，不再提前返回导致界面显示成功但数据未更新。
- 密码输入框查看已保存密码后仍可直接编辑，编辑会清除已显示的旧值，避免无法修改密码。
- 使用已保存凭据恢复会话时，界面明确显示“正在恢复”而不是沿用上一次的同步正常状态。

### 课表 PDF 导出

- 修复课表 PDF 导出参数和请求方式：读取教务系统页面当前学年、学期和动态上下文，使用完整 POST 表单提交。
- 增加请求超时、响应摘要和 PDF 文件头校验；无效响应不会被保存为 PDF。
- PDF 统一保存到 `文档/THEIA/课表`，课表页面的“输出 PDF”旁新增“打开本地文件夹”按钮。
- 浏览器会话失效时，导出流程会等待后台认证完成后再重试，导出结束会回收隐藏来源窗口。

### 课程资料与校园页面

- 课程详情改为应用内资料对话框，可查看课程基本信息、教学资料、课程资源和抓取状态。
- 资料正文在本地预览；打开学校原站仍保持独立的明确操作，不把来源页面内容当成本地事实。
- 后台校园页面支持带请求体的二进制读取和超时控制，修复需要 POST 才能返回文件的来源页面读取。

### 启动与界面

- 启动画面改用北化图书馆图片，并将状态信息固定在图片底部，减少启动等待期间的空白感。
- 调整课表工具栏和课程资料区域的响应式布局，窄窗口下按钮保持可点击且不发生重排遮挡。
- “关于”页面新增 THEIA-Android 项目介绍和 GitHub 仓库入口，明确 Android 10+、只读数据和不执行学校侧操作的边界。

## 安全边界

- 学校密码、Cookie、模型 Key 和原始来源页面仍不进入公开数据、Feed、日志或本地 API。
- 本版本没有扩大自动提交权限；选课决定、作业最终提交和学校系统中的不可逆操作仍由用户确认。
- “打开本地文件夹”不接收渲染器传入的路径，只能打开应用固定的课表 PDF 目录。
