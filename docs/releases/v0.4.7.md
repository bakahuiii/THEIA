# THEIA v0.4.7

## Agent 输出与输入

- 仅把白名单内的 `theia-advisor-tool-call/v1` JSON 作为只读工具调用；其他模型文本原样保存、流式显示和最终显示。
- 工具观察结果明确要求模型直接用自然中文回答；重复工具调用只触发一次内部纠正，不会把协议 JSON 作为用户可见正文。
- Agent 对每个模型轮次设置流式闸门：内部 tool-call JSON 不进入 renderer，最终普通文本仍按 delta 原样流出；后续轮使用精简系统上下文以降低重复输入。
- 对模型偶尔在工具 JSON 后附加解释的情况，解析器只执行开头完整的白名单工具对象并丢弃附加协议噪声；普通话术中的 JSON 不会触发工具。
- 删除最终顾问 JSON、最终回答级引用重写、数据新旧提示、未确定提示、推荐卡片和本地回答修复路径；`CitationVerifier` 仍保留用于工具目录与不可信引用边界。
- Composer 改为 `Enter` 发送、`Shift + Enter` 换行；发送按钮与 Enter 共用同一发送函数。
- renderer 直接渲染普通文本 delta，完成后显示已保存的相同原文。

## OpenAI 传输

- `openai-compatible` 一律使用 Responses API：请求发往 `/v1/responses`。
- 非流式读取 `output_text`；流式读取 `response.output_text.delta`。
- 删除 Chat Completions 请求和 404/405/501 回退分支。
- Responses 请求不再强行发送 `temperature`，兼容 GPT-5 reasoning 模型；HTTP 4xx 错误保留受限服务端原因供诊断。
