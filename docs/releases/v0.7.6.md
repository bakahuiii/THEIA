# THEIA v0.7.6

> 状态：同步体验与作业/测试读取优化。

## 本次更新

- 启动时检查最近一次成功同步时间，超过 24 小时后自动重新同步校园数据。
- 修复同步异常时 Electron 错误提示调用不兼容 API，以及启动后一直停留在“正在更新校园数据”的问题。
- 修复作业红点把已过期任务计入数量的问题。
- 修复 THEOL 未开始在线测试使用 `gotostart(...)` 启动器而无法被识别的问题；过期测试仍会被过滤。
- 作业与测试页面改为“作业 / 在线测试”一级切换，并提供“待完成 / 已完成 / 全部”二级状态筛选。
- 侧边栏将“作业”明确标记为“作业与测试”。
- 课表发生时间重叠时，优先显示非自修课程。

## 兼容与边界

- Windows 安装包继续使用应用 ID `io.github.bakahuiii.theia`，升级路径保持不变。
- 自动更新继续使用腾讯云 COS，GitHub 保留源码和发行存档。
- 作业列表同步只读取列表；任务详情、附件和本地工作包仍需用户进入具体任务后明确触发。
- 最终提交、在线测试回填、选课决定和成绩认定仍由用户在学校系统中确认。
- 安装包未配置可公开验证的 Authenticode 证书，Windows 可能显示未知发布者或 SmartScreen 提示。
