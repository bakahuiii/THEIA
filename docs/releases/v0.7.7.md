# THEIA v0.7.7

> 状态：THEOL 当前学期抓取、作业状态和课表日期显示优化。

## 本次更新

- THEOL 课程与作业扫描只处理当前学期课程，避免历史课程占用抓取时间。
- 同名 THEOL 课程只保留当前课程列表中的首个匹配项，避免重复历史课程被重复抓取。
- 作业与测试扫描增加当前学期过滤统计和逐门课程耗时诊断。
- 修复 THEOL 用“查看结果”链接标记已提交作业、但页面没有“已提交”文字时仍显示为待完成的问题。
- 作业与测试扫描继续忽略已过期的作业和在线测试。
- 课表按周视图的日期抬头由“当天几门课程”改为显示对应日期；日期数字使用稳定的等宽数字样式。

## 兼容与边界

- Windows 安装包继续使用应用 ID `io.github.bakahuiii.theia`，升级路径保持不变。
- 自动更新继续使用腾讯云 COS，GitHub 保留源码和发行存档。
- THEOL 读取仍为只读操作；最终提交、在线测试回填、选课决定和成绩认定仍由用户在学校系统中确认。
- 安装包未配置可公开验证的 Authenticode 证书，Windows 可能显示未知发布者或 SmartScreen 提示。
