# THEIA v0.4.3

## 数据流安全补丁

- 状态加载时只保留 IMAP 净化器写入的 `bodyHtmlVersion: 4` 富邮件正文。
- 旧版、缺少版本戳或包含远程资源/活动内容的邮件 HTML 会在统一归一化边界清除；纯文本正文和邮件元数据仍保留。
- snapshot、Feed、`/v1/emails`、邮件 CSV 和本地静态 Feed 共用同一归一化状态，避免旧缓存绕过 UI 的富正文版本检查。
- 不改变学校侧操作契约；本补丁仍只提供本地读取和同步数据流。
