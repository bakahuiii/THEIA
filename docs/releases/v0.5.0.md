# THEIA v0.5.0

## 重点更新

- Agent、学业分析和数据质量链路统一使用当前快照与受限只读工具；未配置模型服务时，界面会明确提示 Agent 暂不可用。
- CAS 登录后分别验证 JWGLXT 与 THEOL 会话；教务 API 失败时按来源回退到现有浏览器 SSO，并保留来源状态。
- 成绩页使用规范化计算 GPA，同时保留学校提供的 GPA；认证、同步、模型配置和打包回归均采用受限并发测试。
- 发布包继续排除凭据、Cookie、运行期缓存、诊断文件和实验抓取脚本。
