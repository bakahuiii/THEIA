# THEIA v0.7.1

> 状态：源码、测试、构建、Windows 安装包和 packaged smoke 由正式发布流程验收。
> 当前桌面版本元数据为 `0.7.1`。

## 1. 版本定位

`v0.7.1` 是针对 THEOL 作业读取可靠性、校历识别和桌面界面状态反馈的维护版本。它延续 `v0.7.0` 的本地优先数据链路，重点修复真实校园页面结构变化和登录会话失效时用户看不到结果的问题。

## 2. 本次更新

### 2.1 THEOL 作业与测试

- 作业列表支持识别 THEOL 的普通作业、混合式作业和在线测试入口。
- 作业列表支持按页面上的“下一页”继续读取，并设置分页上限与重复链接保护，避免漏掉后续页面或陷入循环。
- 同一任务在多个入口出现时按稳定任务类型和标识去重。
- 作业同步结果记录实际接收条数和完整性状态；部分课程读取失败时不会被误报为完整成功。
- 移动端兜底结果不会覆盖仍未完成的课程扫描错误。

### 2.2 登录失效恢复

- 作业准备工作区和后台作业处理遇到 THEOL 登录超时或“没有权限访问本页面”时，会进入已有认证流程恢复会话，并只重试一次原操作。
- 恢复认证前释放 THEOL 独占队列，认证完成后重新取得队列，避免读取任务与认证任务互相等待。
- 恢复过程清除失效的 THEOL 验证状态，但不删除其他来源凭据或本地数据。
- 认证恢复开始、成功和失败均写入脱敏诊断事件，便于排查“同步正常但作业为空”这类问题。

### 2.3 校历与课表

- 校历 OCR 增强中英文混排和时间识别，补充离线英文 OCR 数据包的打包配置。
- 课表时间列显示节次对应的起止时间；时间未能解析时明确显示待解析状态。
- 校历资源和时间信息继续通过本地缓存与现有数据契约提供给界面。

### 2.4 前端与视觉状态

- 后台作业与测试更新在同步状态区域显示开始、完成和失败状态，不再表现为无反馈的空白列表。
- 设置、关于、界面和常用操作中的图标统一应用圆角裁切，图片标记按容器比例填充并避免内容溢出。
- 调整课表窄屏布局和节次标签尺寸，减少时间文本拥挤和布局跳动。

## 3. 验收范围

- `npm run lint`
- `npm run build`
- `node --test --test-concurrency=4 tests/*.test.mjs`
- Windows x64 NSIS 安装包构建
- packaged smoke 离线启动与 Advisor overview bridge 验收
- 源码归档内容过滤、清单和校验值验证

## 4. 兼容与边界

- Windows 安装包仍使用应用 ID `io.github.bakahuiii.theia`，升级路径保持不变。
- 本版本不改变 Android 客户端的包名、内部存储键或版本号。
- 最终提交、选课决定和成绩认定仍由用户在学校系统中确认；THEIA 的读取、同步和本地归档不会替代学校侧确认。
- 安装包未配置可公开验证的 Authenticode 证书，Windows 可能显示未知发布者或 SmartScreen 提示。
