# THEIA v0.7.4

> 状态：同步与作业读取可靠性维护，完善认证恢复、诊断反馈和关于页面。

## 本次更新

- THEOL 作业与测试改为逐课程读取，抓到一门先提交一门，后台列表扫描不再默认抓取任务详情和附件。
- 识别校园系统的访问频率限制，停止无效重试和兜底请求，前端保留本地数据并给出明确提示。
- 同步域在完成后即可提前提交，慢速来源不会阻塞已经完成的课表、成绩和其他数据更新。
- 作业准备工作区会刷新 THEOL 会话状态；认证恢复后重新校验会话并恢复作业扫描队列。
- 关于页面重新整理 THEIA 品牌区和“关于我”区，补充头像与联系方式，并统一图片图标的圆角裁切。

## 兼容与边界

- Windows 安装包继续使用应用 ID `io.github.bakahuiii.theia`，升级路径保持不变。
- 自动更新继续使用腾讯云 COS，GitHub 保留源码和发行存档。
- 作业列表同步只读取列表；任务详情、附件和本地工作包仍需用户进入具体任务后明确触发。
- 最终提交、选课决定和成绩认定仍由用户在学校系统中确认。
- 安装包未配置可公开验证的 Authenticode 证书，Windows 可能显示未知发布者或 SmartScreen 提示。
