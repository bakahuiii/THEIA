# 考试

## 页面目标

考试页负责展示教务系统里的考试安排，让用户快速看到时间、地点、校区、座号和备注。

## 主要内容

- 学期筛选。
- 全部安排和仅未来考试的切换。
- 考试时间、课程名、考试方式、地点、校区和座号。
- 已过期标记，方便区分已经发生的考试。
- 备注标签，用不同颜色强调补充说明。

## 数据来源

- state.exams
- terms
- startAt
- examTime
- remark
- campus
- seat

## 边界

- 这里只读考试安排，不做考试相关操作。
- 没有未来考试时，只说明当前筛选范围内没有数据，不把它解释成系统故障。

## 细节

### 排序规则

- 先看学期筛选，再看全部或仅未来考试。
- 有有效时间的考试会进入时间排序。
- 未来考试按时间升序，已过期项排在后面。
- 没有可解析时间的条目会靠后处理，避免把未知时间误当成最先发生。

### 显示方式

- 日期栏同时显示考试时间和考试类型。
- 地点栏会合并校区和座号。
- 备注会根据文案映射成不同色阶，方便一眼看出补充说明。

### 空状态

- 选了“仅未来考试”但没有结果时，会明确说明当前筛选范围内没有未来考试。
- 没有考试记录时，会提示同步后再看。
- 这里不做任何考试编辑动作。

## 代码级细节

- ExamsView 的核心状态只有 termFilter 和 visibility，都是本地筛选状态，不会写回任何数据。
- filtered 先用 matchTerm 过滤学期，再按 parseExamTime 排序；同一批里未来考试优先，已过期项后移。
- 视图里每一行都会用 parseExamTime 重新算 timestamp，再决定是否显示“已过期”标签。
- remarkTone 决定备注 badge 的色阶，和课表、成绩页里类似的状态色保持一致。
- 空状态通过 EmptyState 统一输出，避免把“没有未来考试”和“没有任何考试记录”混为一谈。
