# THEIA 功能文档

这个目录放的是按页面拆开的详细说明。FEATURE_OVERVIEW 负责快速浏览，这里负责把单个功能写细。

## 读法

1. 先看概览页，确认你要找的功能名。
2. 再打开对应文档，看它的页面目标、数据来源和边界。
3. 需要排查行为时，优先看“边界”和“相关文件”。

这些页面文档会尽量写到按钮、状态、空态、异常和相关代码的粒度，目标是直接拿来排障，而不是只做一句话简介。

## 约定

- 这些文档写的是当前实现，不写规划稿。
- 页面里出现的新行为或边界变化，应该同步更新这里。
- 如果你只需要一版快速总览，先看 [overview.md](overview.md)。
