# THEIA 功能简介

THEIA 是面向北京化工大学学生的 Windows 校园工作台。它把教务系统、北化在线 THEOL、校园邮箱和常用学习工具集中到一个本地应用中，方便查看、整理、计算和准备学习事务。

## 校园信息

- **校园概览**：查看今天的课程、下一场考试、待办作业、通知，以及课程、考试和成绩数量。
- **课表**：按学期、周次、今日或全学期查看课程；查看教师、教室和上课周次；支持课程冲突提示和教务系统课表 PDF 导出。
- **考试**：查看考试时间、课程、地点、校区、考试方式和座号，并筛选未来考试。
- **成绩**：按学期查看成绩、学分和 GPA；查看成绩趋势、成绩明细及重修等备注。
- **学业进度**：查看培养方案、课程完成情况、已获学分、未通过课程、当前在读课程和学分缺口。
- **我的课程**：查看北化在线 THEOL 课程，按课程名、课程代码、教师、学期和课程类别搜索；登录后静默补充课程基本信息、教学大纲和教学日历入口。打开课程资料浮窗可预览已抓取的页面摘要，按需抓取课程资源目录，并单独下载学习文件到本机缓存。

## 课程与任务

- **抢课**：查询全校教学班和选课批次，按课程、院系、教师、课程类型等条件筛选，保存目标教学班，并在用户指定的时间窗口内执行有限次数的选课尝试。
- **作业与在线测试**：同步 THEOL 作业和测试，按待完成、已提交或全部查看任务。
- **本地工作包**：为任务准备题目、附件、模板和答案文件，便于在本机检查和编辑。
- **模型辅助**：在配置模型服务后生成答案、笔记或论文草稿，将 Markdown 渲染为 PDF，并导入或写入经过格式检查的在线测试答案。
- **提交准备**：打开学校提交页面并选择文件；最终内容检查和提交由用户完成。

## 通知与邮箱

- **校园通知**：集中查看教务系统和北化在线 THEOL 的通知，按标题、来源或摘要搜索并查看详情。
- **校园邮箱**：通过 IMAP 收取邮件列表，搜索邮件，按需读取正文，并将附件保存到用户选择的位置。
- **后台收信**：可设置自动收取间隔，也可随时手动刷新。

## 学习工具

- **校历与教学进程**：查看学年、学期、教学周、假期和特殊日期，预览官方校历、教学进程表和周历。
- **培养计划**：查看当前专业的官方培养计划 PDF。
- **空闲教室**：按时间和条件查询空闲教室；经 Iris 的 `theia classroom <节次>` 会按当前周次、星期和节次实时查询并生成空闲教室图片。
- **体测评分**：导入学校体测结果，按年度查看；也可手动输入体测数据进行本地估算。
- **场馆状态**：查询 MOTION 公开场馆的日期、场地和时间段状态；经 Iris 的 `theia motion <项目>` 每次实时刷新并生成状态表图片。
- **学业预警计算器**：根据 GPA 和已获学分估算页面显示的升年级及预警提示。
- **创新学分**：登记课程、竞赛、大创、论文、专利、讲座、认证和创业等项目，估算创新创业教育学分并查看认定规则。
- **第二课堂**：按德、智、体、美、劳五个维度估算基础分、拓展分和相关门槛，并查看分值表。
- **校园地图**：查看北京化工大学昌平校区校园图和卫星图，支持缩放、拖动和图层切换。

## 学业顾问

- 根据用户提出的问题，按需读取课程、课表、考试、成绩、学业进度、作业、通知、邮箱和体测等本地信息。
- 提供带证据的回答、风险提示、截止事项、课程选择建议和下一步行动。
- 默认使用受限 Agent 模式；用户可在设置中配置模型服务并选择更高的处理预算。该模式仅提供已声明的工具，不提供通用文件系统或命令能力。

## 设置与导出

- 配置统一身份认证、教务系统 API、校园邮箱和模型服务。
- 设置后台同步、查看同步状态和活动记录，并单独重试失败的数据域。
- 导出完整 JSON、THEIA Data Feed、ICS 日历、成绩 CSV，或生成供用户选择的 AI 离线资料包。
- 调整主题、深浅色、界面缩放、背景图片、色板、动效和 3D 背景预设。
- 内置 Iris QQ 校园助手 companion；可在设置中安全保存 QQ Bot 凭据并启停服务，默认展示 `theia status`、`theia today`、`theia agent` 和 `theia motion` 四个 THEIA 指令，其他本机 provider 保留并可从 Iris 控制面板显示。

## 使用边界

- 教务、THEOL、校历、体测和场馆数据会保存在本机，网络暂时失败时尽量保留已有结果。
- 抢课只有在用户明确设置并启动后才会尝试；不会自动退课、评教或办理其它学校事务。
- 作业和在线测试不会由 THEIA 自动完成最终提交，用户必须在学校页面核对并确认。
- MOTION 功能只读取公开场馆状态，不提供预约、取消或支付。
- 学业预警、创新学分和第二课堂页面是本地计算或估算工具，不能替代学校正式认定。
